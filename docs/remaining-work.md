# Project status (historical note)

This page preserves a short status record from development round 3 (the Mentat-Hard test set, revision 3.1), released as v0.1.0. It is not an active roadmap or runbook. The public software and results bundle is MentatBench v0.1.0; start with the [README](../README.md) and [results overview](../results/README.md).

### 2.3 Release gates

The v0.1.0 release recorded its gate results in [check_gates.md](../release/v0.1.0/record/check_gates.md), against a manifest pinned at `defed6a`. The archived record lists gates 1, 2, 7, 9, and 10 as met; gates 6, 8, and 11 as owner-attested; gates 3 and 4 as not applicable; and gate 5 as removed. The results are the measurements now published in the [v0.1.0 bundle](../results/README.md), not a new run.

The old gate run depended on the original private source snapshot, Windows engine binary, external catalogue, and sealed private fixture. The release runner is not included in this checkout, so the archived manifest and gate report do not verify the current public source tree. This heading is retained because the bundle's provenance notes refer to section 2.3.

For the earlier exact-scale track's status, see [exact_scale.md](exact_scale.md).
