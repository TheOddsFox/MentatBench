# Exact scale (historical)

The former exact-scale track explored generated corpora at 10k, 100k, and 1M semantic units. It was retired on 2026-10-27; the long runs were scrapped and the generators and gate code were removed. One early generator repeated a 36-unit template, so its nominal 1M size did not establish 1M distinct semantic evidence.

The run data and engine copy were later deleted. The old 1M gate result cannot be reproduced from this checkout and is not part of the public MentatBench v0.1.0 results. For current results, see the [bundle overview](../results/README.md).
